# Agent rules for AIxTech crypto intel

- This is paper-only research. Never implement live order routing, withdrawal, or storage of trade secrets/API keys with trading permissions.
- Use only synthetic fixtures or public data. No personal data, NRIC, emails, real wallet private keys, or seed phrases in code, docs, or fixtures.
- All changes must pass tests and security checks (redaction, no secrets).
- Disclose AI assistance in commits and PRs.
- Follow zero-trust: redact sensitive patterns, maintain audit lineage.
- Human review required for any strategy or risk-gate changes.
