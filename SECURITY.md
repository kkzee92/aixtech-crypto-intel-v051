# Security policy

## Supported versions
Latest commit on main.

## Reporting a vulnerability
Use GitHub private vulnerability reporting. Do not open public issues for secrets or exploits.

## Built-in protections
- Expanded redaction patterns for keys, seeds, PATs, high-entropy strings.
- Hash-chained multi-hash audit lineage.
- Paper-only mode guards.
- Recommended: gitleaks, ruff security rules, PDPA tripwire in CI.

Research design only. Not a certified security product.
